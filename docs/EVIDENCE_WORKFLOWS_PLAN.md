comparisons, inventing storage owners, trusting library names by default, or
replacing reviewed inventories wholesale. This is an implementation plan; an
unchecked item does not describe a shipped command.

## Acceptance boundaries

Previews never change source, inventory, metadata, verdicts or external state.
Writers validate the complete operation before publishing and reject stale
review inputs. A failed write/build/verification cannot become an earned match.
Literal agreement is distinct from placement; reviewed native identity is
distinct from linked archive ownership. Keep unknown/unsupported evidence
explicit. Reuse current AST, object/format, locked writer and report APIs.

Project migrations preserve customized rules and native sources. Generated
coverage exports can move, but authoritative metadata is changed only through
its owning APIs. Existing experiments and receipt files stay ignored.
